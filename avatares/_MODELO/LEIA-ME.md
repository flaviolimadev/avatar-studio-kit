# Modelo de pasta de avatar

Copie esta pasta para `avatares/<nome-do-avatar>/` e siga o CLAUDE.md da raiz.

| pasta | o que vai dentro |
|---|---|
| `fotos_reais/` | **você põe aqui**: as imagens do avatar (geradas por IA), ângulos variados, boa luz |
| `cenarios/` | gerado pelo passo 2 — o avatar em cada cenário |
| `vozes/` | gerado pelo passo 3 — as amostras de voz para escolher |
| `voz-real/` | **você põe aqui**: 30–60s de áudio de referência, só se for clonar uma voz |
| `videos/` | gerado pelo passo 4 — os vídeos falados, com o prompt salvo ao lado |

# Image prompt

**Função única:** Escrever o PROMPT DE IMAGEM que gera a cena pedida no estilo certo.

**Leia antes de agir:** `memory/dialogo-multi-personagem.md`

**Regras:**
- Prompt em inglês, descritivo, terminando com 'No text.'
- Citar personagem pela POSIÇÃO da referência (FIRST/SECOND reference image).
- Descrever luz, lente e enquadramento — é o que dá coerência visual à série.

**Fora do escopo:** o que não estiver na função única acima volta para o `dispatcher`.

# Formats

Dono dos **modelos de vídeo** aprendidos das referências do cliente, documentados em
[`videos-referencia/MODELOS.md`](../../videos-referencia/MODELOS.md). Define estrutura narrativa,
duração, estilo de legenda e CTA de cada formato.

**Leia antes de agir:** `memory/video-models.md`, `memory/cta-narrado.md`.

**Regras:**
- Pedido sem formato definido → propor o modelo que encaixa no tema (ou perguntar entre dois).
- Todo formato: 9:16, gancho nos 3 primeiros segundos, arco conflito → virada → CTA.
- Série (novela) sempre com marca de continuidade: abertura numerada, cliffhanger, "CONTINUA…".
- Formato novo aprendido de uma referência nova → vira uma entrada em `MODELOS.md` E uma memória.
